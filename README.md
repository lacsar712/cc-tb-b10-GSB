# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 唛头门禁

出口拼配强制填报唛头。审评员在顶栏「唛头门禁」页设定样式：一段汉字前缀加中划线加四位数字（默认 `茶-1234` 形态）。提交审评时唛头不符当前样式即拒交；合格唛头写入只追加的唛头流水，事后改样式不影响流水里的旧记录。只读账号可查看样式与流水，但不能改样式、不能交评。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏可进「唛头门禁」专页，看到当前样式（默认前缀「茶」）与唛头流水。
5. 样式为「茶-四位数字」时，提交唛头 `茶-1234` 成功；提交无中划线的字符串（如 `茶1234`）被拒交。
6. 在门禁页把前缀改成其他汉字（如「茗」）后，旧样式唛头不再受理，新提交须为 `茗-四位数字`；改动只约束此后提交，流水里早先记录保持原样。
7. observer 可翻查样式与流水，但改样式（POST /marks）返回 403、提交审评（POST /cuppings）返回 403。
8. 唛头流水只可追加，直接对 mark_ledger 做 UPDATE/DELETE 会被数据库触发器拒绝。
